# Guiding Principles

Every feature added to Atlas should:

- Solve a real creator problem.
- Save time.
- Reduce manual work.
- Improve organization.
- Be simple to use.
- Integrate naturally with existing workflows.

Features that do not support these principles should be reconsidered before implementation.
